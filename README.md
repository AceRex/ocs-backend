# OCS Backend — Cloud Synchronization & Licensing Engine

**OCS (Organised Church Service)** is an integrated church presentation and media platform designed to automate worship projection, sermon archiving, and mobile stage coordination for churches globally.

The **OCS Backend** is the reliable cloud synchronization, authentication, and licensing backbone that connects OCS Web, Desktop Workstations, and Mobile Companions into a unified, secure church technology ecosystem.

## ☁️ Core Platform Services

### 1. Unified Authentication & Licensing Quotas
- **60-Day Free Trial Engine**: Automatically provisions and enforces a standardized 60-day (2-month) full-feature evaluation window for all new church registrations.
- **Tiered Multi-Device Quota Management**: Coordinates station limits across subscription tiers (Mini, Standard, Large, and Premium), seamlessly authorizing active desktop display computers and mobile stage companions.
- **Secure Token Cryptography & CSRF Protection**: High-security token issuance and cryptographic deep-link validation for seamless browser-to-desktop sign-in flows.

### 2. Live WebSocket Real-Time Communication
- **Instant Admin Event Bus**: Powers real-time notification feeds for support tickets, platform downloads, suggestions, and church feedback.
- **Remote Controller Coordination**: Low-latency event streaming that facilitates rapid device pairing and stage state synchronization.

### 3. Transactional Ministry Communications
- **Automated Welcome & Onboarding**: Guides new church administrators through setting up their presentation stations upon registration.
- **Self-Service Password Recovery**: Secure, time-limited password reset workflows to ensure church AV operators never get locked out before Sunday service.
- **Support Notification Dispatch**: Alerts engineering and ministry success teams whenever a church files a technical question or assistance ticket.

### 4. Ministry Downloads & Feedback Infrastructure
- **Multi-Platform Analytics**: Audits and records desktop and mobile application downloads across macOS, Windows, Android, and iOS.
- **Community Suggestions & Testimonials**: Gathers feedback, feature requests, and impact stories from church tech directors to drive continuous product improvement.

## 🌐 The OCS Ecosystem

- **OCS Desktop**: The sanctuary presentation workstation for voice-driven scripture projection, dual-screen foldback, and sermon archiving.
- **OCS Mobile**: The wireless stage companion for pastors and worship leaders, featuring live teleprompter control, intercom, and scripture lookup.
- **OCS Web**: The cloud portal for church subscriptions, downloads, documentation, and support ticketing.
- **OCS Backend**: The cloud API engine orchestrating authentication, real-time messaging, and multi-device licensing.
